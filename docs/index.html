概要

About This Project

TEI/XML準拠

Text Encoding Initiative (TEI) ガイドラインに準拠したXMLデータとして翻刻テキストを構造化。人名・地名・校訂情報を体系的にマークアップしています。

テキスト・画像対照

IIIF対応の画像ビューワーと縦書きテキストを並べて表示。原本画像と翻刻テキストを対照しながら閲覧できます。

アノテーション

人名・地名・日付・時刻の自動ハイライト、校訂情報・注記の表示など、研究利用に資するアノテーション機能を備えています。
